# claude-skills

Claude skills. Each folder is one skill.

## 1. Skills

| Skill | What it does |
|---|---|
| [`enterprise-deal`](enterprise-deal/SKILL.md) | Enterprise sales coach built from Jen Abel's method on Lenny's Podcast (the $1M to $10M ARR playbook). Deal review, price and structure, proposals and champion kits, objections, cold notes to executives, call review, first enterprise hire. Run `/enterprise-deal`. |

## 2. Install

Claude Code:

```
git clone https://github.com/lukehalley/claude-skills.git
cp -r claude-skills/<skill> ~/.claude/skills/
```

Claude apps: zip the skill folder and upload it as a custom skill in
Claude's settings.
